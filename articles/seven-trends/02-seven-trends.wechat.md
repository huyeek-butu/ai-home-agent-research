## 引言

当大模型从"聊天框"走向"行动者"，家庭这一最复杂、最高频、最私密的物理空间，正成为 AI Agent 落地的关键战场。以 WorkBuddy 这类具备任务调度与工具调用能力的智能体为代表，AI 正从"听懂指令"进化为"主动管家"——这一转向被学界概括为 Personal LLM Agents，即以大模型为推理核心、具备意图理解与任务规划能力的个人智能体范式 Li et al., 2024。

本报告系统叠加 2024—2026 年权威外部来源，对七大趋势逐条验证、修正与扩展：(1) 主动工作流编排、(2) 跨品牌联邦控制、(3) 具身智能、(4) 多模态情境感知、(5) 端云协同与隐私优先、(6) 长期记忆与情感陪伴、(7) 垂直场景深化。

研究发现，七大趋势并非齐头并进，而是呈现清晰的"已验证商用—基础设施成型—偏前瞻"三级分布。IDC 预测 2025 年中国智能家居出货 2.81 亿台（同比 +7.8%），并将"家庭垂域大模型"列为关键方向 IDC, 2024；Anthropic 开源的 MCP 协议已被捐赠至 Linux 基金会、公共 Server 超 1 万个，成为 Agent 连接异构设备的"事实标准" Anthropic, 2025。与此同时，具身家务人形、情感真实陪伴仍受制于泛化能力、成本与责任归属，专家判断真正入户需 5—10 年乃至更久。本报告旨在为产业界、研究者与监管者提供一幅可验证、有边界的家庭智能体演进地图。

## 1. 主动工作流编排：自然语言定义全屋智能的落地验证

### 核心论点
家庭智能体正从"人发指令、设备被动响应"的规则时代，迈向"理解意图、自主规划并执行多步任务"的主动工作流编排阶段。该趋势已非纯概念：2025年前后，美的、小米、亚马逊等已推出主动编排产品，并结合 COLMO、天猫精灵等方案，共同验证了"自然语言定义全屋智能"的工程可行性；但落地仍受限于预设技能与场景模板，长链条可靠性亦待验证。

### 一、论据：概念辨析、产业落地与关键技术

**1. 概念辨析：被动应答 → 主动编排 → 动态规划。** 传统智能家居核心是 IFTTT（"若…则…"规则引擎），用户须手动配置触发条件与动作，系统机械执行 云海仰望, 2026。"主动工作流编排"更进一步：智能体理解高层意图后，自主完成"任务分解→工具调用→多设备协同→结果校验"闭环，并依成员状态、预算与偏好实时调整路径——即基于大模型的动态任务规划（Dynamic Planning）。学界将此类系统定义为 Personal LLM Agents，以大模型为推理核心，具备意图理解、任务规划、工具使用与个性化数据管理能力 Li et al., 2024；2024年研究进一步以本地小模型构建"家庭智能体"，通过传感器状态主动推断隐性需求、无需显式指令即可行动，性能可媲美 GPT-4 Yin et al., 2024。

**2. 产业落地：多条已验证路径。**（a）美的"小美AI智能体"整合空气、水、烹饪、光影、安防与能源六大系统，经"感知—决策—执行"闭环使家电从被动响应进化为主动服务 封面新闻, 2025；数据显示美居APP已连接超1.259亿设备、嵌入该智能体的版本服务超1700万用户、日均交互近3000万次、意图识别准确率95% 网易, 2025；其中 Air Agent 基于室内外空气、用户习惯与第三方健康数据动态生成策略并联动空调、新风等设备，Cooking Agent 可识别烹饪阶段、自动控火除烟 封面新闻, 2025。（b）小米2025年发布 Miloco，基于端侧视觉语言大模型 MiMo-VL-Miloco-7B，通过标准化 MCP 协议打通米家与 Home Assistant 开源社区，支持"用自然语言定义全屋智能" 量子位, 2025；小米 AIoT 平台截至2025年6月已连接 IoT 设备达9.89亿台 搜狐/智东西, 2025。（c）亚马逊2025年2月发布 Alexa+，基于生成式 AI 重构、具备 agentic 能力，可在后台自主导航网络完成任务并"在重要时刻主动建议" Amazon, 2025；IDC 研究经理指出其用户采用智能家居功能的速度为经典 Alexa 两倍 Android Central, 2025。（d）互补案例——美的旗下 COLMO 于2025 WAIC 发布 AI 管家，以"多维感知—自主学习—推理规划—决策执行"闭环实现跨设备动态协调 美的官网, 2025；天猫精灵空间智能 Agent 2.0 基于通义大模型长期分析行为习惯主动推送"夜间阅读模式"等场景 搜狐, 2025。

**3. 关键技术：动态规划 + 工具调用编排。** 小米 Miloco 以"应用层"作为决策中枢负责能力调度与 MCP 服务适配 量子位, 2025。MCP（模型上下文协议）是连接 AI 与外部系统的开放标准，截至2025年底已有超1万活跃公共 MCP 服务器、被 ChatGPT、Gemini、Copilot 等采用，并由 Anthropic 捐赠至 Linux 基金会旗下 Agentic AI Foundation Anthropic, 2025；小度亦上线 MCP Server，可操控1800+生态厂商 新浪, 2025。厂商侧亦在推进推理引擎多元化，美的即融合美言与 DeepSeek 等第三方大模型做推理过程 齐鲁晚报, 2025。本地化"消息处理器—智能体—控制器"三层结构可抑制小模型幻觉、提升可靠性 Yin et al., 2024。

### 二、分析：能力边界与局限

尽管已验证，边界仍明显。**其一，依赖预设技能与场景模板**：当前能力多围绕空调、照明等封闭子场景，美的六大 Agent、COLMO 的预设场景链均在既有能力边界内重组，跨品牌长任务仍受技能约束；行业互联互通（Wi-Fi/蓝牙/Zigbee/Thread 多协议难互通）被视作根本瓶颈 搜狐, 2025。**其二，长链条可靠性不足**：Google 曾公开承认 Home/Nest 的 Assistant 可靠性倒退、指令误判、例程不完整 India Today, 2025；Alexa+ 仍处早期访问、云端依赖带来延迟。**其三，价值待证**：有观点指出 LLM 擅长创造却不擅稳定重复执行，需与传统机器学习结合，付费价值亦待验证 Android Central, 2025；IDC 亦提示2025年中国智能家居出货预计2.81亿台、同比+7.8%，但家庭垂域大模型仍处"从帮你到懂你"初级阶段 IDC, 2024。

### 三、小结

综上，"主动工作流编排"已从概念走向局部落地：美的六大 Agent、小米 Miloco（MCP+自然语言）、亚马逊 Alexa+（主动建议）、COLMO 与天猫精灵共同证明家庭智能体可基于大模型实现动态任务规划。然而落地仍受限于预设技能、长链可靠性与跨生态协同，距"完全自主编排"尚有距离——这恰指向第2章将讨论的跨品牌联邦控制（MCP）议题。

## 2. 跨品牌联邦控制：MCP 统一接口层下的多生态打通

### 论点

家庭智能体的"跨品牌联邦控制"正从愿景走向**基础设施成型**：MCP（模型上下文协议）正成为 Agent 连接异构设备的"统一接口层"，小度、小米等头部厂商已基于该协议打通多个生态。但须清醒看到：设备层（Matter/Thread）与能力层（MCP）分处不同层次，跨云账号壁垒与非智能设备的 RPA 兜底，意味着"一个大脑调度全屋"尚未完全闭环。

### 论据与论证

**① 生态割裂：联邦控制的起点痛点。** 长期以来，米家、Apple HomeKit、华为鸿蒙及主流 Matter 生态彼此割裂，用户选购设备前被迫"先选生态"。IDC 在 2024 年底报告中预测，2025 年中国智能家居市场预计出货 2.81 亿台、同比增长 7.8%，同时将"连接方式统一推动设备革新"列为关键方向之一，侧面印证互联标准的价值 (IDC: Top 10 Insights on China's Smart Home Market in 2025)。行业分析亦将智能家居"孤岛效应"归因于不同协议、品牌、平台间难以互通 (Matter协议：打破智能家居孤岛效应的通用语言)。

**② MCP：AI 的"USB-C"。** Anthropic 于 2024 年 11 月开源 MCP，定位为连接 AI 应用与外部系统的开放标准；2025 年 11 月 25 日的周年规范引入"基于任务的工作流"（异步操作、任务状态查询、隔离），并称其已从"小实验"成长为连接数据与应用的"事实标准" (MCP 一周年规范)。至 2025 年底，活跃公共 MCP Server 已超 1 万个，并被 ChatGPT、Gemini、Microsoft Copilot 等主流产品采用，Anthropic 更将其捐赠予 Linux 基金会下属 Agentic AI Foundation，以确立厂商中立治理 (Anthropic 捐赠 MCP 至 Linux 基金会)。其核心价值在于让 Agent 以"一次编写、处处集成"的方式调用各品牌 API，扮演跨平台中间件。

**③ 落地案例：从协议到多生态打通。**

- **小度 MCP Server**：2025 年 7 月，小度科技上线物理世界交互 MCP Server，开发者仅需配置 API 密钥即可用自然语言操控 **1800 余家生态厂商**的智能设备，并支持"一句话场景渲染"（如"营造浪漫观影氛围"自动调暗灯光、关窗帘、设温）(小度首发物理世界交互 MCP Server)。
- **小米 Miloco**：基于自研端侧视觉语言模型 MiMo-VL-Miloco-7B，通过标准化 MCP 协议封装，实现**米家生态与 Home Assistant（全球最大开源智能家居社区）生态的无缝打通**，支持自然语言定义全屋智能 (小米给智能家居做了个"大模型大脑")。
- **Home Assistant**：作为开源中枢已突破 200 万活跃安装，并于 2025 年 3 月成为首个通过 CSA Matter 认证的开源项目，整合 Zigbee、Z-Wave、Matter 等协议 (Home Assistant officially Matters)。

**④ 设备间依赖编排：联邦控制的核心难点。** 真正的"全屋调度"不止于点对点控制，更在于理解设备间的因果依赖。正如小度所演示，"营造观影氛围"需协同调光、关窗帘、设定空调——这要求 Agent 将"开投影仪"语义展开为联动关窗帘、降幕布、切音响模式的一连串有序操作。清华等学者在《Personal LLM Agents》综述中指出，个人 LLM 智能体须具备工具调用与任务规划能力，方能自主解决复杂问题 (Personal LLM Agents, arXiv:2401.05459)；MCP 2025-11 规范新增的"基于任务的工作流"正是为这类多步骤编排提供协议级支撑。

**⑤ 局限与未来：与 Matter/Thread 互补而非替代。** 须客观指出三处未竟之处：（a）**层次差异**——Matter/Thread 解决设备层"能否互联"（数据模型、配网、本地控制），MCP 解决能力层"Agent 如何调用"，二者互补；Matter 全球认证产品已超 5900 款、中国贡献近 2/3 (对话Matter,2025中国智能家居生态再进化)。（b）**跨云账号壁垒**——即便协议统一，各生态云账号与权限仍彼此独立，社区亦指出部分厂商仍强制云端注册甚至内置追踪器 (Home Assistant 社区讨论)。（c）**非智能设备兜底**——老旧或哑设备仍需 RPA 或桥接器接入。此外业界对 MCP 存质疑：有分析指出其安全（认证、多租户隔离）、上下文膨胀与工具质量参差等问题尚未根治，宜作为高层框架下的"管道"而非主导集成 fabric (MCP: Understanding Its Limits)；亦有观点认为 MCP 从"网红"回落为"基建"，高频能力将回归原生集成 (诞生才一周年,MCP凉了)。这些批评本身反向印证：协议已成底座，生产级成熟度仍在演进。

### 小结

跨品牌联邦控制的基础设施已初步成型：MCP 作为统一接口层，叠加小度、小米等落地实践，使"一个大脑调度多生态"从概念走向可用；Matter/Thread 在设备层持续补课，与 MCP 形成层次互补。然而跨云账号壁垒、非智能设备兜底与协议安全成熟度，仍是"全屋联邦"真正闭环前必须跨越的门槛。

## 3. 具身智能：短期调度型落地与家务人形前瞻鸿沟

### ① 概念：从数字代理到具身智能，"大脑+躯体"架构

具身智能（Embodied AI）被业界视为"智能机器人的最高形态、具身智能的最佳载体"（我与未来｜人形机器人走入百姓家中还需要多久？），其本质是把原本只在数字世界运行的 AI Agent 赋予可感知、可行动的"躯体"，进入物理世界执行任务。在本研究框架中，家庭具身智能体遵循"大脑（Agent 高层规划）+躯体（机器人底层运动控制）"的分层架构：上层 Agent 负责意图理解、任务规划与多设备编排，下层机器人/家电负责执行。这一"大脑—躯体协同"思路已被产业实践印证——北京人形"天工"机器人依托"慧思开物"平台，由具备空间感知与分层规划的"大脑"先规划路径，再调用负责泛化抓取的"小脑"技能库执行动作，并将反馈回传形成任务闭环（具身智能冷思考）。快思慢想研究院院长田丰亦以"灵魂（算力与交互逻辑）与肉体（硬件设备）"类比，指出计算范式升级必然重塑物理终端（田丰：2026 AWE大展，家电"AI进化论"）。

### ② 短期落地：扫地/陪伴/康养的协作调度已先行

真正率先落地的并非"全能人形保姆"，而是以家庭 AI 中枢统一调度的"非人形"协作网络。AWE2026 上，MOVA 以 AI 中枢将扫地机、个护、宠物等设备纳入同一"感知—判断—协同调度层"，实现跨场景数据共享与动态调度（AWE2026直击：MOVA重构生态）；小度"主动管家"展示：摄像机识别孩子回家→判断学习场景→联动护眼灯，地面弄脏即调度扫地机器人清扫，厨卫水汽超标自动关闭涉水家电（从"听懂指令"到"主动管家"）；CES2026 追觅描绘扫地机检测空气质量后调度空气净化器、料理机完成后通知扫地机清残渣的协同图景（CES深度观察：智能清洁四大关键词）。在康养侧，深圳养老护理院已引入星尘智能 Astribot S1 辅助推轮椅、递茶、陪打太极，其 DuoCore 快慢协同系统兼顾"本能反应与深度思考"（养老院里来了机器人助理）。市场层面，2025 年京东"618"期间具身智能品类增速超过 17 倍（央广网报道）；2025 年养老机器人市场约 91 亿元、适老化智能家居约 602 亿元（中商产业研究院）。

### ③ 人形家务前瞻与鸿沟：技术/价格/安全/家庭复杂环境

然而，能"真正干活"的家务人形机器人仍处前瞻阶段，横亘四道坎。**技术上**，银河通用创始人王鹤指出家庭场景复杂度远超工业环境，需海量数据训练，"从单项技能到综合服务的跨越仍需时日"（央视：保姆机器人来了）；优理奇方面坦言 Wanda2.0（售价 8.8 万元起）"还不能成为全能保姆、不能完全取代保姆"，现阶段更现实的路径是"人机协同"（同上）。**环境上**，央广网报道多位企业负责人认为，家庭环境的个性化与动态性（新购物品、布局调整）使机器人泛化能力遭遇严峻挑战，且家庭数据采集还涉及隐私回传难题（央广网报道）。值得肯定的是，部分"中间场所"已开始验证：银河通用 Galbot G1 已在北京近十家无人药店"上岗"，在约 50 平方米店铺执行 5000 余种商品的盘点、补货、取送、打包（央视：保姆机器人来了）。

### ④ 专家判读：5–10年入户与产业界质疑

学界与产业界对"入户时间表"存在相对一致的谨慎判断，亦不乏质疑。浙江大学宋伟认为近 3 年不可能，5 年内仅特定环节突破，5–10 年相对合理；智瞰深鉴李昱慧同样判断需 5–10 年（具身智能叩响家门还要多久）。北极光创投合伙人黄河则更审慎，认为行业"整体还在幼儿园水平"，难度最高的人形机器人与家庭场景"恐怕要到最后才能水到渠成"，时间尺度或需 10–20 年（具身智能还要翻过哪些大山）。资本侧亦有冷思考：金沙江创投朱啸虎直言"谁会花十几万元买一个机器人去干这些活？"（中国青年报）；36氪评论警示"口号式繁荣"，强调家庭场景拐点须是技术成熟度、成本可控性与场景适配性的系统性突破，而非演示台的一次性成功（人形机器人的家庭场景拐点就这样到了？）。与之相对，优必选给出 2028 年部分家庭场景切入的渐进预期（36氪）。

### ⑤ 小结

综上，具身智能在家庭场景呈现鲜明的"两层分化"：短期看，以 Agent 为大脑、以扫地/陪伴/康养设备为躯体的调度型协作网络已实质落地，构成可感知的当下；中长期看，能承担叠衣、烹饪、收纳的家务人形机器人仍受制于泛化能力、成本、安全与家庭复杂环境，专家普遍判断真正入户需 5–10 年、乃至更久。产业应优先夯实"大脑+躯体"分层架构与中间场所（养老院、无人药店、零售）验证，警惕将演示能力等同于交付能力，方能在"实验室到客厅的最后一公里"中稳步前进。

## 4. 多模态情境感知：视觉与激光雷达融合的商用突破

> 对应趋势 4：从"听见"到"看懂"家庭。本章论证多模态情境感知已进入"已商用"阶段，并客观呈现其局限。

### 一、概念：从"听见"到"看懂"

传统智能家居以语音交互为核心，依赖"用户指令—设备执行"的单模态链路（AI大模型与智能家居融合应用全面解析）。多模态情境感知（multimodal context awareness）则指系统通过视觉、环境传感、毫米波/激光雷达等多维数据源的融合，对家庭空间、人体状态与行为意图进行联合理解（Wang et al., 2025, IEEE IoT Journal）。海信视像牵头制定的《智能家居场景下多模态大模型技术要求》IEEE 国际标准于 2025 年 4 月正式立项，标志着行业开始为多模态交互、家居环境理解建立统一技术框架（海信多模态大模型 IEEE 标准立项）。本质区别在于：单语音是"等指令"，多模态是"主动懂"——设备无需唤醒即可基于环境变化预判需求。

### 二、视觉商用突破：跌倒检测与食材识别

适老看护是视觉落地最快的场景。萤石 S10 视频通话摄像机搭载自研视觉跌倒检测算法，识别异常行为后快速触发告警并联动紧急联系人，全流程无需人工干预（中国电子报：萤石让智慧家庭多点"人情味"）。更具突破性的是中国移动在 2025 世界移动通信大会发布的"AI 视感融合"方案：基于 FTTR 全光网络与 3D 激光雷达，实现 **0.5 秒精准识别跌倒、闯入、坠床**等异常行为，且通过 3D 点云替代画面避免直拍隐私区域（新华网浙江：中国移动创新打造"AI视感融合"家庭安防解决方案）。

该方案并非概念演示：2026 年 5 月数字中国建设峰会上，基于移动视联网的 3D 光感知多端联动系统亮相，以"无感立体、隐私安心"模式守护独居老人（新华网浙江：中国移动视联网重塑智慧养老新范式）；同期绥化移动联合华为等落地**全国首个**"3D 光感知+摄像头+FTTR"一体化智慧康养项目，异常行为识别准确率达 **95% 以上**，3 秒内触发电话/APP/监控大屏三重告警（腾讯新闻：绥化移动数智化赋能养老服务）。

在健康管理侧，冰箱视觉识别已商用。卡萨帝"AI 鉴赏家"冰箱搭载"AI 之眼"可毫秒级动态识别 **210 种食材**并自动建档（环球网：卡萨帝用AI科技破千年储鲜困局）；海信璀璨真空冰箱通过图像识别与 AI 算法精准识别**食材种类与新鲜度**，给出科学保鲜方案（网易：AI升级会是冰箱行业下一个技术风口吗）；AWE2025 上多品牌冰箱均内置摄像头实现食材自适应管理（电器杂志：从AWE2025看冰箱进化）。"看懂"食材已从营销概念转为现实功能。

### 三、环境传感主动调节：看不见的舒适

多模态不只靠"看"，也靠"感"。华为鸿蒙智家 2025 年发布的主动健康空气解决方案，智能调度中央空调、新风系统与人体及空气传感器，对家中 CO₂、甲醛、PM2.5、温湿度等 **6 项指标**检测优化；当传感器识别 CO₂ 过高，联动推窗器开窗并启动新风循环（新浪财经：华为鸿蒙智家主动健康空气方案）。海林全环境智能控制系统通过人体感应雷达，在有人进入时下发舒适模式、无人超 10 分钟自动切节能模式（海林自控：全环境智能控制）。行业方案进一步将温湿度、CO₂、人体存在传感器统一调度暖通设备，实现"人来开机、人走停机"的节能联动（中国工控网：空调/暖通/新风智能控制系统）。环境感知已从单一读数升级为闭环主动调节。

### 四、行为意图理解：从识别状态到预判行动

更高阶的情境感知是"理解意图"。小米 Miloco 2.0 将摄像头、手环、声音传感器综合感知，结合家庭记忆提供主动服务——如识别女主人久坐姿态不佳时关联腰部病史即时提醒（腾讯新闻：小米Miloco 2.0有记忆能认人）。百度 Create2026 大会上，超能小度演示：摄像机检测地面污渍即调度扫地机器人清洁，并基于生活习惯预判服务（虎克科技：百度Create2026小度家庭AI管家）。在出门场景，系统可融合门窗传感器、地理围栏、天气与日历信息，在出家门前提醒带伞、限号或遗漏物品（微提醒：出门提醒器智能科技）。业内观点认为，行为意图理解是家庭智能体从"工具"转向"管家"的分水岭（BetterYeah：AI大模型与智能家居）。

### 五、隐私与误报：商用的两难

视觉方案的首要挑战是隐私。传统摄像头因持续采集影像在卧室、卫生间等私密空间难以部署，而这恰是致命跌倒高发区（腾讯新闻：绥化移动智慧康养）。3D 激光雷达以"点云替代画面"部分化解此矛盾——仅识别人体轮廓与姿态，不采集面部与衣着（新华网浙江：中国移动视联网）。但**观点**指出，点云方案在精细姿态判断上仍弱于高清视觉，二者各有适用边界。

误报与复杂光照是另一瓶颈。厨房等场景的水渍易与反光、油污混淆导致误判，需专门算法优化（数智教育：厨房卫生管理分析预警）；扫地机器人领域研究亦指出，纯视觉在低光照、透明物体识别上存短板，多传感器融合虽更鲁棒却抬高成本（INDEMIND：视觉黑科技让扫地机器人开启"先知"模式）。学界在多模态协同感知（MMCP）上的实验显示，跨设备特征融合较非协同策略平均精度提升 **18%**，但需在通信开销与感知性能间权衡（Wang et al., 2025）。事实表明，商用系统在复杂光照、遮挡与个体差异下仍会触发误报，需持续迭代。

### 六、小结

多模态情境感知已进入"已商用"阶段：萤石视觉跌倒检测、中国移动 3D 激光雷达 0.5 秒识别、冰箱食材视觉识别、华为主动空气调节均规模落地。技术主线是从单语音到"视觉+传感+雷达"融合，价值主线是从被动响应到主动预判。但隐私区覆盖、误报与复杂光照仍是待解约束——这也正是端云协同与本地推理（如 Arm 平台本地 LLM，兼顾隐私与低延迟）持续发力的方向（Arm：本地LLM推理重塑智能家居隐私与延迟）。

## 5. 端云协同与隐私优先：端侧 AI 家居中枢的引擎化

### 核心论点
端侧 AI 家居中枢已从概念验证步入规模商用，"家庭的本地大脑"通过端云协同承担语音识别、行为分析等隐私敏感型日常任务。本章论证其商用成熟度，并剖析算力、功耗、成本与隐私协同的现实约束，指出端侧是"智能的执行层"而非"全知的云端大脑"。

**① 概念：家庭的"本地大脑"与端云协同。** 所谓"端云协同"，指端侧设备负责数据采集、轻量推理与实时响应，云端承担大规模训练与复杂推理，二者动态调度的分布式架构（T/TAF 316—2025 端云协同人工智能服务用户数据保护要求，2025）。中国信通院将端侧大模型概括为"本地化、轻量化、个性化、协同化"四大特征，并明确"对时延敏感的实时任务由端侧处理，算力需求高的复杂任务分流至云端"的端—边—云三级范式（中国信息通信研究院，2025）。Arm 基于树莓派 5 的开源方案（Arm, 2025）即是一台"本地大脑"参考实现：以 Ollama 在 Cortex-A76 上运行 DeepSeek/Qwen 等最高 7B 模型，亚秒级响应、全离线、零持续成本。

**② 端侧小模型商用进展（"已商用"的实证）。** 多项事实支持端侧中枢已落地：其一，小米 2025 年第三季度 AIoT 连接设备突破 **10 亿台**，其 Miloco（Xiaomi Local Copilot）方案以 MiMo-VL-Miloco-7B 端侧视觉语言模型为核，部署于家庭边缘设备、视觉数据本地计算（量子位/小米, 2025；36 氪, 2025；新浪科技, 2026）。其二，面壁智能与易来 2025 年 6 月发布 Yeelight Pro S 系列 AI 智慧屏，集成 MiniCPM，**行业首款本地部署大模型的纯端侧家居中枢**，全程离线语音（自动化网, 2025）。其三，Apple 于 iOS 26 / macOS 26 开放 Foundation Models 框架，提供约 30 亿参数端侧模型，离线、免费且隐私优先（Apple Machine Learning, 2025）。IDC 亦将"头部厂商发力家庭垂域 AI 大模型"列为 2025 年中国智能家居十大洞察之一（IDC, 2024）。

**③ 记忆分层与可遗忘。** 端云协同天然支持记忆分层：小米 Local Copilot 采用"数据最小化"流程，**敏感信息在设备端处理、非必要数据不上传**（36 氪, 2025）。可遗忘方面，端侧本地存储理论上可被彻底清除，但云端长期记忆需受控——这正是监管重点：T/TAF 316 要求提供"用户数据删除、撤回同意"机制（T/TAF 316—2025）。学术上，王腾等提出 FedUR 差分隐私联邦遗忘机制，使模型在统计意义上满足"被遗忘权"（王腾 等, 2025）。**有观点指出**（techpolicy.press, 2025），AI 长期记忆（非参数记忆）会显著增强个性化说服力，若缺乏用户主权与平滑衰减机制，将滑向操控风险，故"默认遗忘、主动留存"应成为设计原则。

**④ 联邦学习隐私协同。** 联邦学习使多家庭 Agent 在不共享原始数据前提下协同优化通用模型。Nature 两篇 2025 年论文分别将其用于智能家居非侵入式负荷监测（FL-WGAN）与 IoT 设备隐私识别（FL-HDECOC，96.2% 准确率 + 差分隐私）；浙大等提出的 Fed-SE 框架让分散智能体隐私协作，平均成功率 66%，较联邦平均高 18%（arXiv:2512.08870, 2025）。**但需客观看待**：联邦学习在家庭场景仍处早期——设备异构、频繁模型更新的通信开销、模型投毒等攻击是公认落地挑战（智能家居联邦学习技术解析），且联邦遗忘本身亦可能泄露隐私（王腾 等, 2025）。

**⑤ 成本 / 功耗 / 能力权衡。** 端侧的硬约束清晰。一是**算力天花板**：纯本地仍难处理长篇生成、超高精度图像等重任务，复杂推理须回云端（科普中国, 2025）。二是**"功耗—算力—成本"不可能三角**与"内存墙"（百度百科：端侧大模型）。后摩智能吴强指出传统架构约 90% 功耗耗在数据搬运，其 M50 芯片以 10W 提供 100–160T 算力支撑百亿级参数端侧运行（36 氪 WISE2025, 2025）；vivo 副总裁周围亦坦言"卷通用人工智能不现实"，转向仅 2GB 内存、约 750mA 的 3B 轻量模型（每日经济新闻, 2025）。**业界主流判断**是端云协同为务实折中：简单、隐私敏感任务本地，复杂任务云端。

### 小结
端侧 AI 家居中枢是七大趋势中最早规模落地的方向之一——小米 10 亿设备、面壁×易来纯端侧中枢、Arm/Apple 端侧模型均已商用，配合 T/TAF 316 等标准与联邦学习研究，隐私优先的"本地大脑"范式成形。但其能力边界明确：端侧是实时、隐私的执行层，复杂推理与全局优化仍依赖云端；功耗、成本、跨设备异构构成现实约束。趋势的下一步在于芯片能效跃升（存算一体）、记忆可遗忘的工程化，以及联邦学习从论文走向家庭。

## 6. 长期记忆与情感陪伴：养老机器人落地与情感真实性争议

### 论点

家庭管家型 AI Agent 若要跨越"工具"到"伙伴"的门槛，长期记忆与情感陪伴是两个无法回避的能力维度。就技术而言，记忆分层与可遗忘、隐私可控已具备可落地的工程范式；就落地而言，养老机器人正借政策东风成为最具确定性的突破口。然而，情感是否"真实"、是否诱发依赖与误导，以及数据隐私与责任归属如何界定，仍是横亘在规模化之前的核心瓶颈。

### 论据

**一、长期记忆技术：从分层存储到"被遗忘权"。** 清华大学等多机构联合综述《Personal LLM Agents》提出个人 LLM 智能体的五级智能框架（L1–L5），其中 L4 为"记忆与上下文感知"，要求智能体理解用户历史数据、感知当下情境并主动提供个性化服务，L5 则演进为可代表用户处理复杂事务的"数字分身"（自主化身，Autonomous Avatar） (Personal LLM Agents: Insights and Survey about the Capability, Efficiency and Security)。该综述将"记忆力（Memorizing）"列为三大基础能力之一，定位为记录用户数据、回忆过往事件、总结知识与自我进化的基础。工程实践层面，业界主流采用"短期交互—中期会话—长期知识"三层记忆架构，并普遍引入时间衰减与遗忘机制；关键隐私共识是"用户主权"——记忆的最终控制权须归属用户，需提供明确授权、可视化管理与一键删除，从而将敏感数据隔离在最易挥发的短期层 (如何让你的 AI 智能体学会遗忘)。

**二、情感陪伴落地：政策驱动的养老机器人窗口期。** 数据显示，我国 60 岁及以上人口在 2024 年末已达 3.1031 亿，首次突破 3 亿，银发经济规模约 7 万亿元 (据央广网报道)。政策层面，工业和信息化部、民政部于 2025 年 5 月联合印发《关于开展智能养老服务机器人结对攻关与场景应用试点工作的通知》，试点期 2025—2027 年，明确将"情感陪护"列为重点场景，并要求居家类产品完成不少于 200 户家庭的应用验证 (智能养老服务机器人结对攻关与场景应用试点工作的通知)。民政部披露，2025 年首批已有 32 个攻关与应用试点项目入围，并累计遴选 308 项智慧健康养老产品 (2025 养老服务十件大事)。产业研究估计，国内养老机器人市场规模 2024 年已突破 300 亿元，预计 2025 年达 500 亿元 (据央广网报道)。

**三、情感真实性争议：缓解孤独 vs. 制造幻象。** 学术层面，哈佛商学院 De Freitas 等发表于《Journal of Consumer Research》（2025）的研究提供了首批因果证据：与 AI 陪伴对话降低孤独感的效果与真人互动相当，且主要源于"被倾听感"，但该效果为短期、需持续使用 (AI Companions Reduce Loneliness)。反方观点则指出，AI 的"共情"本质是概率计算与模式匹配而非真实情感，存在明显"奉承"与单向迎合倾向，长期使用可能抬高用户面对现实关系的心理门槛，导致社交能力退化与"情感外包"、"认知外包" (情感陪伴还是算法依赖)。

### 分析

上述材料显示，技术可行性与情感真实性是两层不同性质的问题：记忆分层与养老政策落地属可验证的工程与行政事实，而"AI 是否真正陪伴"则是哲学与伦理命题。监管已迅速回应争议：国家网信办 2025 年底发布《人工智能拟人化互动服务管理暂行办法（征求意见稿）》，要求显著标识"本服务由人工智能驱动，不具备人类情感意识"，对连续使用超 2 小时者弹窗提醒，并建立心理危机人工接管与老年人紧急联系人机制 (解读《人工智能拟人化互动服务管理暂行办法》)。国际层面，欧盟《人工智能法案》于 2024 年 8 月生效，将工作与教育场景中的情绪识别列为禁止类应用，凸显全球对"情感计算"的审慎共识 (欧盟人工智能治理规则与发展)。综合来看，情感陪伴的瓶颈集中在四点：① 情绪数据属高度敏感信息，隐私与数据安全要求极高；② 当 AI 误判或延误危机干预时，责任主体难以界定；③ 情感真实性的边界——是否应被允许模拟情感、制造拟亲密关系；④ 对老年人、未成年人等弱势群体的认知操纵与依赖风险。

### 小结

长期记忆与情感陪伴，是家庭 AI 管家从"执行指令"走向"理解并陪伴人"的关键一跃。养老机器人借政策与需求双重驱动率先落地，验证了陪伴型 AI 在家庭场景的真实价值；但"陪伴"二字必须以透明、可控、可退出为前提，技术应被定位为真实社会连接的"补充"与"演练场"，而非替代。唯有在记忆主权与情感边界上建立清晰护栏，家庭 AI 管家才能既温暖又安全。

## 7. 垂直场景深化：养老/育儿/健康赛道的政策与商业双驱动

### 核心论点
当通用大模型能力趋于成熟，AI 家庭智能体的价值落地正从"全能助手"转向"垂直场景深化"。在七大趋势中，趋势 7（垂直场景深化）的先行样板集中于养老、育儿、健康三大刚需赛道：它们兼具需求刚性、付费意愿与数据闭环，且在政策与市场的双轮驱动下率先跑通，形成清晰的商业化分层。本章论证养老场景已获"政策+市场"双验证，育儿与健康管理中枢初现雏形，同时厘清责任归属、数据隐私与医疗合规三大待解挑战。

### 一、垂直深化的底层逻辑

通用智能体若要真正创造价值，必须锚定高频、高痛点的具体场景，而非停留在"能聊天"的表层能力。养老、育儿、健康恰好满足"需求刚性×付费可能×数据可闭环"三重条件，成为垂直深化的第一梯队。事实层面，国家统计局数据显示，2025 年 5 月我国服务机器人产量同比增长 13.8%、达约 121.6 万台（央视网，2025）。宏观政策亦同向：国务院办公厅 2024 年 1 号文件将"发展银发经济"列为国家级专题，明确"打造智慧健康养老新业态"、推进服务机器人等智能设备在居家、社区、机构养老场景集成应用（国务院办公厅，2024）。这表明垂直深化并非企业单方面试水，而是政策与产业共识的合流。

### 二、银发管家：政策与市场双驱动，"已验证"

**（论据·政策）** 政策端形成自上而下推力：国办发〔2024〕1 号将"推广应用智能护理机器人、家庭服务机器人"写入培育潜力产业条款（国务院办公厅，2024）；北京市海淀区 2025 年《智慧养老院建设方案》更进一步，将"跌倒检测设备""用药管理智慧化（提醒+缺药报警）""认知障碍筛查与 AI 评估""情感陪护机器人"明确列为示范型智慧养老院的硬性要求，并强调"明确科技产品的应用边界、做好数据隐私保护、明确各方责任"（海淀区民政局，2025）。民政部披露，截至 2025 年 4 月底已累计创建智慧健康养老示范企业 238 家、示范街道 387 个，发布 3 批推广目录遴选 228 项产品与 204 项服务（民政部，2025）。

**（论据·市场）** 市场端增速印证刚需：中商产业研究院测算，中国养老机器人市场规模 2024 年约 79 亿元（同比 +19.7%）、2025 年约 91 亿元，2026 年预计达 104 亿元；适老化智能家居 2025 年约 602 亿元，2026 年预计 662 亿元（中商产业研究院，2026）。

**（论据·案例）** 落地已具象化：温州龙湾为困难老人家庭安装毫米波雷达跌倒检测仪与睡眠监测仪，依托 AI 多模态算法将误报率从 77.3% 降至 6.1%，"呼呼睡管家"曾在老人呼吸异常时自动预警、及时挽救生命，并通过"家属—村社—镇街—民政"四级响应链闭环处置（温州民政局，2025）；优理奇 Wanda2.0、星尘智能 Astribot S1 等陪护/护理机器人已在养老院与 C 端交付（央视网，2025）。

**（分析）** 从政策文件到地方方案，再到市场数据与真实救险案例，银发管家的"跌倒+用药+认知评估"三支柱已跨越概念验证，进入规模化推广前夜——"已验证"成立。

### 三、育儿管家：从"带娃神器"到发育风险早期识别（初现）

育儿管家以"学习日程/屏幕时间管理"与"发育监测"两条线切入。杭州"杭小育"智能体上线以来已服务近 72 万名家长，30 余万个家庭通过居家自查实现发育风险早期识别，知识库整合 8.6 万余条专业内容（钉新闻，2025）。屏幕时间维度，部分产品以摄像头识别儿童走神、低头并实时提醒，家长端生成"分心报告"（今日头条，2025）。

**观点与质疑并存**：教育专家提醒，AI 评估结果仅为参考、不能替代医学诊断，过度依赖还可能弱化亲子情感联结（钉新闻，2025）；隐私层面，多款 AI 玩具内置超广角摄像头与高敏麦克风，部分默认勾选"数据用于商业研究"，存在家庭对话与环境数据泄露风险（今日头条，2025·平安黄冈）。可见育儿管家尚未"验证"，仍处初现阶段。

### 四、健康管理中枢：从被动记录到主动规划（初现）

方向是连接手环、体脂秤、睡眠带与体检报告，主动规划饮食与运动。2025 年华为发布首款鸿蒙 AI 智能手表 WATCH 5，"微体检"60 秒生成 17 项健康指标，腕上小艺融合 DeepSeek 提供"主动式健康管理"，并通过"家庭空间"共享家人健康数据（腾讯新闻，2025）。行业层面，苹果、华为、三星、小米等已布局集成心率、血氧、睡眠、摔倒检测的多功能设备；2025 年讯飞医疗联合爱奥乐推出首款搭载医疗大模型的 AI 血压计，实现"精准测量+AI 提醒+持续管理"闭环（今日头条，2025）。**分析**：多设备数据汇聚为"中枢"提供了物理基础，但跨品牌数据打通与"主动规划"的个体化能力仍处早期。

### 五、商业化分层与责任/合规挑战

**（分层已清晰）** 中商产业研究院总结养老机器人三大细分赛道呈现"康复靠医疗买单、护理靠 B 端降本、陪伴靠 C 端体验"的鲜明商业化分层：康复机器人凭医疗壁垒借力医保/长护险跑通医院与机构场景；护理机器人因成本高、信任缺仍困于机构端；陪伴/监护机器人向"真安全刚需"回归，依赖 C 端消费与适老化采购（中商产业研究院，2026）。这一"康复—医疗、护理—B 端、陪伴—C 端"格局已可视为"已验证"。

**（挑战 1·责任归属）** 海淀方案要求"明确各方责任，建设及使用产生的风险由相关责任方承担"（海淀区民政局，2025）——恰说明责任链尚未法定化；央视指出稳定性与安全性（含数据隐私）仍是家庭落地前提（央视网，2025）。

**（挑战 2·数据隐私）** 家庭数据采集天然涉及隐私，央广报道直言需"立法、出台标准让消费者信任数据回传"（央广网，2025）；育儿设备的摄像头/麦克风风险尤为突出。

**（挑战 3·医疗合规边界）** 育儿发育评估、健康指标解读一旦被用户等同于医学诊断即越界。专家强调 AI 是"辅助工具而非替代者"，需监管完善算法标准、打击夸大宣传（钉新闻，2025）。

### 六、小结

垂直深化在养老赛道已获政策与市场双重验证，育儿管家与健康管理中枢初现雏形；"康复靠医疗、护理靠 B 端、陪伴靠 C 端"的商业化分层格局清晰。但要真正跨越从实验室到家庭的"最后一公里"，必须在责任归属、数据隐私、医疗合规边界三方面建立治理框架——这既是挑战，也是下一阶段产业竞合的焦点。

## 结论

本报告叠加 2024—2026 年权威来源交叉验证，勾勒出家庭智能体从"概念"走向"客厅"的演进图谱。核心结论是：七大趋势并非同步成熟，而是呈"已验证商用—基础设施成型—偏前瞻"三级梯队。

第一梯队"已验证商用"覆盖趋势 1、4、5 与趋势 7 的养老场景：美的"小美 AI"服务超 1700 万用户、意图识别准确率 95% 网易, 2025；多模态跌倒检测（中国移动 3D 激光雷达 0.5 秒识别）与食材视觉识别均已规模落地 新华网浙江, 2025；端侧中枢方面，小米 AIoT 连接设备突破 10 亿台、面壁×易来发布行业首款纯端侧家居中枢 自动化网, 2025；养老赛道更获政策与市场"双验证" 中商产业研究院, 2026。

第二梯队"基础设施成型"以趋势 2（跨品牌联邦控制）为代表：MCP 成为统一接口层，小度 MCP Server 可自然语言操控 1800+ 厂商设备 新浪科技, 2025，但跨云账号壁垒与协议安全成熟度尚未闭环。

第三梯队"偏前瞻"集中于趋势 3（具身家务人形）与趋势 6（情感真实陪伴）。专家判断家务人形真正入户需 5—10 年 中国青年报, 2025；情感陪伴虽有降低孤独感的因果证据 De Freitas et al., 2025，却引发依赖与责任归属争议，已触发国家网信办《人工智能拟人化互动服务管理暂行办法（征求意见稿）》 国家网信办, 2025。

共性瓶颈有四：硬件标准（Matter/Thread 与 MCP 层次互补）、安全对齐、责任归属与成本功耗（端侧"不可能三角"）。总体判断：家庭智能体正以"大脑+躯体""端云协同"的务实架构稳步前进，但"实验室到客厅的最后一公里"取决于治理框架与芯片能效的双重突破。
