## 一、项目简介

本仓库由个人研究者（不土老师）维护，目标是把 AI 家庭智能体、开源持续学习方向的系列思考**长期沉淀**为可检索、可复用、可分发的内容资产。

- **研究方向**：AI 家庭智能体的产业趋势、技术路径、对工商业的溢出效应，以及开源持续学习对大模型能力演化的重塑。
- **内容形态**：原始研究笔记（Markdown）+ 深度调研报告（带外部权威引用）+ 每篇报告的多平台发布物料。
- **发布渠道**：知乎（首选，外链可点）、行业媒体投稿、微信公众号、GitHub（沉淀主阵地）。
- **核心诉求**：沉淀优先；知乎与行业媒体分批发，不一次性砸完。

## 四、物料格式说明

每篇深度报告目录下含 5 类文件（以 `01-trend-report.*` 为例）：

| 文件 | 用途 |
|---|---|
| `<NN>-<name>.clean.md` | 去内部标记 / 双链的干净正文，适合二次加工 |
| `<NN>-<name>.zhihu.md` | 知乎稿：保留外部链接，可直接粘贴发布 |
| `<NN>-<name>.wechat.md` | 公众号稿：正文去外链、参考文献保留 URL，适配秀米 / 135 |
| `<NN>-<name>.pdf` | A4 排版 PDF，含可点击目录与链接 |
| `<NN>-<name>.pptx` | 12 页演示文稿，适合演讲 / 分享 |
